# PulmoAcoustic

Adaptive smartphone-only contactless respiratory monitoring research project.

## Current release
PulmoAcoustic v0.4 Complete

The full Android source, DSP implementation, validation harness, research dataset catalog, and APK-build workflow are packaged in the release archive:

- `PulmoAcoustic_v0.4_complete.zip`

## Important
This is a research prototype, not a medical device. Do not use it for diagnosis or to replace clinical equipment.

## Quick start
1. Download the release archive.
2. Extract it.
3. Open the extracted folder in Android Studio.
4. Run the app on a compatible Android phone.
5. Follow the in-app calibration and chest-position scan.
6. Use the measurement confidence indicator and repeat low-confidence measurements.

## Validation
The project includes DSP validation and public respiratory dataset references. Real accuracy must be established against a reference respiratory measurement device across subjects and phone models.

## Repository
This repository is the source/home for the PulmoAcoustic research project.
