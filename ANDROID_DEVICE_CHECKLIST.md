# Android Device Checklist

Before collecting data on a phone:

- Android 8 / API 26 or newer
- Built-in speaker
- Built-in microphone
- 48 kHz input preferred; app can select a supported fallback
- Phone audio is not muted
- Speaker and microphone openings unobstructed
- No active call/voice-recorder app
- No Bluetooth headset unless deliberately testing that configuration
- Quiet room
- Battery above 20% for research sessions
- Run device calibration after changing phones

The app should be evaluated separately for each phone model. Do not assume that a carrier or gain setting that works on one phone is optimal on another.
